Certainly! Based on your notes, here is the breakdown of process vs. thread scheduling:

Process Scheduling:

Involves the OS scheduler deciding which entire process gets CPU time. Processes are heavyweight and have their own isolated memory space. Switching between processes (context switching) is expensive due to memory map overhead.

description [Notes: Operating Systems Ch. 3, Pg 12]
Thread Scheduling:

Involves deciding which thread within a process gets CPU time. Threads share the same memory space as their parent process. Context switching between threads is much lighter and faster.
